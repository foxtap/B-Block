# B-Block 文件夹恢复工具 · 使用说明

> 适用：上锁/解锁流程中断，文件夹被隐藏 + 被拒绝访问，软件里却看不到记录、门户 `.lnk` 也没了。
> **只恢复，不删除** —— 脚本不会移动、重命名、删除任何文件。

---

## 一、先搞清楚到底发生了什么

故障状态通常是这三件事同时成立：

| 现象 | 原因 |
|---|---|
| 文件夹看不见 | 被设了 `HIDDEN` + `SYSTEM` 属性 |
| 点进去提示无权限 | ACL 里被插入一条针对「当前用户」的 `DENY 全部访问` |
| 软件列表里没有、门户 lnk 没了 | 解锁流程中途失败，配置记录与实际状态不同步（常见于卸载重装、配置被重置） |

**好消息**：文件本身一直都在，只是被藏起来 + 被拒之门外，恢复是纯权限操作，不涉及解密。

---

## 二、在对方电脑上怎么用（3 步）

### 第 1 步：把整个 `恢复工具` 文件夹拷过去
U 盘、微信、QQ 传都行，双击不动的东西，解压到桌面即可。

### 第 2 步：双击 `一键恢复.bat`
- 如果弹出蓝色 PowerShell 窗口提示策略限制 → 右键 `一键恢复.bat` → **以管理员身份运行**
- 一般情况**不需要管理员**，因为是恢复「本用户自己创建的文件夹」

### 第 3 步：按菜单操作
```
  1) 扫描电脑，找出被隐藏/被拒绝访问的文件夹     ← 不知道文件夹在哪儿就选这个
  2) 恢复指定路径的文件夹                        ← 知道路径就选这个
```
选择后会再问一句：**「是否【实际执行】修复？输入 y 执行，其它键只预演不改动」**
- 直接回车 = 只预演，把将要做的操作列出来，**磁盘上一个字节都不改**
- 输入 `y` + 回车 = 真正修复

## 三、命令行用法（给熟练的人）

```powershell
# 预演（推荐先看这个）
.\B-Block文件恢复.ps1 -Mode Recover -Path "D:\某文件夹\账号密码"

# 真正执行
.\B-Block文件恢复.ps1 -Mode Recover -Path "D:\某文件夹\账号密码" -Apply

# 扫描指定盘符
.\B-Block文件恢复.ps1 -Mode Scan -Root "D:\" -Apply
```

## 四、脚本实际做了什么（可审计）

按顺序执行，全部是系统自带命令：

1. `icacls <路径> /remove:d *<当前用户SID> /T /C /Q` —— 删掉那条 DENY 拒绝规则
2. `icacls <路径> /grant:r <当前用户>:(OI)(CI)F /T /C /Q` —— 重新授予完全控制（含子项继承）
3. `attrib -h -s <路径>` —— 清掉隐藏/系统属性
4. 验证能否正常列出内容

> ⚠️ **顺序不能反**：DENY 还在的时候 `attrib` 会直接报「拒绝访问」（已实测），必须先解 DENY 再清属性。

每次运行会在脚本同目录生成 `恢复日志_时间戳.txt`，保留操作证据。

## 五、万一还是不行

| 情况 | 处理 |
|---|---|
| 提示「拒绝访问」且不是管理员 | 右键 → 以管理员身份运行；仍不行就先 `takeown /F "路径" /R /A /D Y` 夺所有权 |
| 文件夹名/路径都忘了 | 用 `-Mode Scan`，脚本会扫桌面/文档/下载/图片，并提示可额外输入盘符 |
| 恢复后想重新保护 | 打开 B-Block 重新加密即可，旧的无用 `.lnk` 可手动删 |
| 文件确实读不出来（磁盘坏） | 这是硬件/文件系统问题，与 B-Block 无关，先别写入新数据 |

---

## 六、建议顺手做的两件事（防再次发生）

1. **导出万能恢复文件**：B-Block 主界面 → 导出恢复文件 → **离线保存**（这是密码/密钥的兜底）。
2. **避免中途强杀**：解锁过程中不要强制结束进程；自动上锁的「用完即锁」宽限期建议设 ≥1 分钟，别设 0，给程序留完成收尾的时间。
